# 创作智库与设定管理模块功能定义

## 1. 模块概述

创作智库与设定管理模块是AI小说创作工具"创世之笔"的核心功能之一，为用户提供小说世界观、角色、物品、地点、势力等设定元素的智能管理工具，以及创作资源的集中管理和智能检索功能。该模块旨在帮助用户积累和管理创作素材，构建完整、一致的小说设定体系，通过AI辅助和可视化工具，降低设定管理的复杂度，提高创作效率。

## 2. 核心功能

### 2.1 世界观管理

- **世界管理**：
  - 创建和管理多个世界设定
  - 支持复杂的世界层级结构（主世界、子世界、维度、位面等）
  - 世界基本信息和核心概念管理

- **世界观结构**：
  - **能量体系**：定义世界的能量类型（魔法、斗气、灵气等）
  - **力量等级**：构建修炼等级体系和晋升规则
  - **通用技能**：管理世界中的通用技能
  - **能量形态**：定义具体能量表现形式
  - **力量代价**：设置使用力量的代价系统
  - **文明文化**：创建不同的文明类型和文化特征
  - **社会阶级**：定义社会阶层结构和流动性
  - **文化习俗**：管理节日、仪式、礼仪、禁忌等传统
  - **经济体系**：构建货币、贸易、产业等经济系统
  - **政治体系**：定义政体、权力结构、法律体系
  - **历史脉络**：记录历史纪元、重大事件、历史人物
  - **地理区域**：构建世界的地理结构和区域划分（支持树状结构）
  - **维度位面**：支持多维度、多位面的复杂世界设定
  - **天体星球**：管理天体和星球信息
  - **自然法则**：定义世界的物理法则和特殊规则
  - **种族设定**：管理不同种族信息
  - **生物类型**：管理普通生物和特殊生物

### 2.2 角色管理

- **角色基本信息**：
  - 姓名、性别、年龄、种族、职业
  - 角色类型（主角/配角/反派等）
  - 重要程度等级（1-10）
  - 存活状态

- **角色详细设定**：
  - **外貌描写**：详细的外貌特征描述
  - **性格特点**：性格特征、心理模式
  - **背景故事**：成长经历、重要事件、人际关系
  - **角色弧线**：角色的成长和变化历程
  - **动机目标**：角色的核心动机和追求目标
  - **秘密与谎言**：角色隐藏的秘密和谎言

- **角色能力**：
  - **身体能力**：体力、速度、耐力等
  - **智力感知**：智慧、感知、精神力等
  - **特殊天赋**：天生能力和天赋
  - **当前等级**：当前能力等级
  - **能力详情**：具体能力列表和熟练度

- **角色装备与物品**：
  - 常用装备
  - 特殊物品
  - 个人物品
  - 关键物品

- **角色关系**：
  - 家庭成员、挚友、师徒关系
  - 同事、仇敌
  - 爱情关系、复杂情感
  - 暗恋、情感变化

### 2.3 地点管理

- **地点基本信息**：
  - 名称、类型、描述
  - 所属区域
  - 重要程度等级

- **地点详细设定**：
  - **地理环境**：位置、地形、气候、特殊环境
  - **势力控制**：控制势力、守卫力量
  - **人口构成**：人口规模、种族分布
  - **经济文化**：经济状况、文化特色

- **地点结构**：
  - 整体布局、功能区域
  - 重要建筑、秘密区域
  - 防御设施、弱点

- **地点资源**：
  - 主要资源、潜在危险
  - 进入限制、生存条件

### 2.4 物品管理

- **物品基本信息**：
  - 名称、类型、描述
  - 稀有度等级
  - 重要程度

- **物品属性**：
  - 物理属性、特殊效果
  - 使用要求、耐久度
  - 来源、历史传承

- **物品归属**：
  - 制造者、当前所有者
  - 获取方式

### 2.5 势力管理

- **势力基本信息**：
  - 名称、类型、描述
  - 势力状态、标志
  - 重要程度

- **势力详细设定**：
  - **组织架构**：领导体制、等级制度、部门设置
  - **决策机制**：内部决策流程
  - **成员管理**：成员规模、核心成员、人才储备
  - **招募培训**：招募方式、培训体系
  - **纪律规则**：晋升路径、纪律规定

- **势力目标**：
  - 短期目标、中期计划、长期愿景
  - 秘密计划

- **势力关系**：
  - 盟友关系、敌对关系
  - 从属关系、中立关系

### 2.6 关系图谱

- **可视化展示**：
  - 使用力导向图可视化展示角色-地点-势力-物品间的关系
  - 不同类型的节点使用不同的颜色和图标
  - 关系强度和类型通过连线的粗细和颜色区分

- **交互功能**：
  - 支持手动拖动调整节点位置
  - 点击节点可查看详细信息
  - 支持缩放、平移视图
  - 支持筛选特定类型的节点和关系

- **关系管理**：
  - 支持手动添加、删除、修改关系
  - 自动检测和提示潜在的关系冲突
  - 支持关系的层次化展示

### 2.7 全局搜索

- **搜索功能**：
  - 全文检索和关键词检索
  - 支持自然语言检索
  - 支持模糊搜索和相关搜索
  - 跨实体全局搜索

- **知识图谱**：
  - 可视化展示设定元素和情节之间的关联
  - 以图形化方式展示概念间的关系
  - 支持图谱的缩放、平移和节点点击

### 2.8 标签系统

- **标签管理**：
  - 为实体添加标签分类
  - 支持标签的创建、编辑、删除
  - 标签颜色自定义
  - 使用次数统计

- **标签检索**：
  - 按标签筛选实体
  - 支持多标签组合查询

### 2.9 数据管理

- **数据存储**：
  - 记录所有设定元素（角色、地点、物品、势力等）
  - 支持数据的自动备份和恢复

- **数据操作**：
  - 支持数据的分类和标签管理
  - 支持数据的批量操作（导入/导出/删除）
  - 支持数据的版本控制和历史记录
  - 支持数据的导入和导出（如JSON、CSV格式）

### 2.10 历史与文明

- **历史脉络**：
  - 历史纪元划分
  - 重大历史事件记录
  - 文明发展历程
  - 历史人物

- **文明管理**：
  - 文明类型和发展阶段
  - 政治、经济、科技、魔法水平
  - 文化特征、宗教信仰、禁忌
  - 历史起源

- **社会体系**：
  - 社会阶级结构
  - 典型职业、生活水平
  - 教育机会、社会流动性

## 3. 界面设计

### 3.1 整体布局

- **顶部导航栏**：
  - 模块标题：创作智库
  - 操作按钮：新建设定、导入设定、导出设定
  - 视图切换：列表视图/图谱视图

- **左侧边栏**：
  - 设定分类：世界观、角色、物品、地点、势力
  - 搜索框：快速搜索设定元素
  - 筛选条件：按类型、重要性、标签等筛选

- **主内容区**：
  - 设定元素列表（列表视图）
  - 关系图谱（图谱视图）
  - 设定详情编辑表单

- **右侧边栏**：
  - 相关设定：显示与当前选中元素相关的其他设定
  - 智能建议：基于当前设定提供AI建议
  - 操作历史：显示最近的操作记录

### 3.2 核心组件

- **世界观编辑器**：
  - 树形结构展示世界观元素
  - 选项卡式子模块编辑（能量体系、文明、历史等）
  - 时间线编辑器

- **角色编辑器**：
  - 多步骤表单，包含基本信息、外貌性格、背景故事、能力、装备、关系等部分
  - 角色卡预览组件
  - 关系选择器

- **物品/地点/势力编辑器**：
  - 结构化表单，包含基本信息和详细属性
  - 关联选择器
  - 重要性等级滑块

- **关系图谱组件**：
  - ECharts力导向图
  - 节点和连线的自定义样式
  - 交互式操作工具栏

- **全局搜索组件**：
  - 搜索输入框
  - 搜索结果列表
  - 快速跳转功能

## 4. 技术实现

### 4.1 前端实现

- **技术栈**：React + Ant Design + ECharts + React-DnD
- **核心组件**：
  - Ant Design的Form、Tree、Card、Tabs组件构建设定管理界面
  - ECharts力导向图实现关系图谱
  - React-DnD实现节点拖拽功能
  - 富文本编辑器用于详细描述编辑

- **交互逻辑**：
  - 实时保存设定变更
  - 动态更新关系图谱
  - 智能建议的实时生成和展示

### 4.2 后端实现

- **技术栈**：Python + Flask + SQLite + OpenAI API
- **核心功能**：
  - 设定数据的CRUD操作
  - 调用OpenAI API生成设定内容
  - 关系数据的处理和分析
  - 全文检索和标签管理

- **API设计**：
  - `POST /api/ai/generate_worldview`：生成世界观
  - `POST /api/ai/generate_character`：生成角色
  - `GET /api/projects/<id>/settings`：获取项目设定列表
  - `POST /api/settings`：创建新设定
  - `PUT /api/settings/<id>`：更新设定
  - `DELETE /api/settings/<id>`：删除设定
  - `GET /api/settings/<id>/relations`：获取设定关系
  - `GET /api/worlds/<id>/stats`：获取世界统计信息

## 5. 用户流程

### 5.1 进入创作智库

1. 用户在项目编辑界面点击"创作智库"按钮
2. 系统进入创作智库与设定管理模块
3. 显示设定元素列表和关系图谱

### 5.2 管理世界观

1. 用户创建或选择一个世界
2. 用户在子模块中管理能量体系、文明、历史、地理等设定
3. 用户保存世界观设定

### 5.3 创建角色

1. 用户点击"创建角色"按钮
2. 用户填写角色的基本信息和详细设定
3. 用户关联角色到相关设定元素
4. 用户保存角色设定

### 5.4 管理物品/地点/势力

1. 用户点击"新建"按钮，选择设定类型
2. 用户填写设定的基本信息和详细属性
3. 用户关联设定到其他相关元素
4. 用户保存设定

### 5.5 使用关系图谱

1. 用户在关系图谱中查看设定元素之间的关系
2. 用户点击节点查看详细信息
3. 用户手动添加、删除、修改关系
4. 系统自动更新关系图谱

### 5.6 使用全局搜索

1. 用户在搜索框输入关键词
2. 系统跨实体检索并显示结果
3. 用户点击结果快速跳转到对应设定

## 6. 功能价值

- **设定一致性**：通过集中管理设定元素，确保设定的一致性和连贯性
- **智能辅助**：利用AI生成设定内容，降低设定构建的难度
- **可视化管理**：通过关系图谱直观展示设定元素之间的关系
- **资源整合**：集中管理所有创作资源，提高资源利用效率
- **效率提升**：通过结构化表单和快速操作，提高设定管理效率
- **创作支持**：为后续的故事创作提供完整、详细的设定基础

## 7. 未来扩展

- **设定模板**：提供不同类型的设定模板，如"玄幻世界模板"、"科幻世界模板"等
- **设定导入/导出**：支持设定的导入和导出，方便在不同项目间共享
- **设定验证**：使用AI验证设定的合理性和一致性
- **设定可视化工具**：提供更丰富的设定可视化工具，如3D地图编辑器等
- **跨项目资源共享**：支持在不同项目间共享和复用资源

创作智库与设定管理模块将成为用户构建小说世界的核心工具，通过AI辅助和可视化技术，帮助用户创建完整、一致、丰富的小说设定体系，为故事创作提供坚实的基础。
