# AI生成系统模块功能定义

## 1. 模块概述

AI生成系统是AI小说创作工具"创世之笔"的核心功能之一，为用户提供智能化的内容生成能力。该模块涵盖世界观元素生成、概念融合、检查点机制、会话管理等多种生成策略，帮助用户快速生成高质量的创作内容，同时保持与世界设定的连贯性。

## 2. 核心功能

### 2.1 世界观元素生成

#### 多类型生成
- **角色生成**：
  - 根据设定信息生成完整角色
  - 支持深度生成和灵感生成两种模式
  - 生成内容包括：外貌、性格、背景、能力、关系等

- **地点生成**：
  - 根据世界设定生成地点
  - 包含地理特征、建筑、人口等信息
  - 自动关联到相关势力和文明

- **势力生成**：
  - 生成完整的势力设定
  - 包含组织结构、目标、历史等
  - 自动建立与其他实体的关系

- **物品生成**：
  - 生成具有特殊属性的物品
  - 物品稀有度和价值评估
  - 来源和传承背景

- **关系生成**：
  - 基于已有实体生成关系网络
  - 关系类型和强度设定
  - 关系描述和建议

#### 生成策略
- **批量生成**：
  - 支持一次性生成多个元素
  - 分批处理避免token限制
  - 生成过程中实时显示进度

- **渐进生成**：
  - 先生成基础框架
  - 再逐步细化各部分
  - 保持生成内容的连贯性

- **上下文传递**：
  - 确保分批生成的内容保持连贯
  - 自动维护生成上下文
  - 支持长文本分段生成

### 2.2 概念融合

#### 重复检测
- **相似度分析**：
  - 检测新生成内容与已有内容的重复
  - 支持多种相似度算法
  - 可配置的相似度阈值

- **去重处理**：
  - 自动过滤高度相似内容
  - 保留有价值的变体
  - 生成去重报告

#### 融合策略
- **智能合并**：
  - 将新生成内容与已有设定智能融合
  - 保留关键特征消除冲突
  - 生成融合后的完整内容

- **属性协调**：
  - 协调不同来源的属性值
  - 解决设定冲突
  - 保持世界一致性

### 2.3 检查点机制

#### 状态保存
- **自动保存**：
  - 生成过程中自动创建检查点
  - 保存当前生成状态和上下文
  - 支持定时保存

- **手动保存**：
  - 用户可随时创建检查点
  - 检查点命名和描述
  - 保存完整的生成环境

#### 状态恢复
- **中断恢复**：
  - 从最近的检查点恢复生成
  - 避免重新开始
  - 节省时间和资源

- **版本回溯**：
  - 回溯到任意历史检查点
  - 比较不同版本的内容
  - 支持选择性恢复

### 2.4 会话管理

#### 会话追踪
- **会话记录**：
  - 记录每次生成会话
  - 会话元数据（时间、用户、参数等）
  - 会话内容完整保存

- **会话状态**：
  - 追踪会话进行状态
  - 支持暂停和继续
  - 会话超时处理

#### 多会话支持
- **并行会话**：
  - 支持多个并发生成会话
  - 会话隔离和资源管理
  - 避免相互干扰

- **会话切换**：
  - 快速切换不同会话
  - 保留会话历史
  - 支持会话导出和导入

### 2.5 生成配置

#### AI提供商
- **多提供商支持**：
  - OpenAI (GPT-4, GPT-3.5)
  - Anthropic (Claude)
  - Google AI (Gemini)
  - Azure OpenAI
  - SiliconFlow

- **提供商切换**：
  - 运行时切换AI提供商
  - 统一的生成接口
  - 降级策略

#### 参数配置
- **生成参数**：
  - Temperature（创造性）
  - Max Tokens（长度限制）
  - Top P（采样策略）
  - Frequency Penalty（重复惩罚）
  - Presence Penalty（话题新鲜度）

- **预设模板**：
  - 不同场景的预设参数
  - 自定义模板管理
  - 模板导入导出

### 2.6 提示词管理

#### 模板管理
- **模板类型**：
  - 角色生成模板
  - 地点生成模板
  - 势力生成模板
  - 物品生成模板
  - 关系生成模板

- **模板编辑**：
  - 可视化模板编辑器
  - 变量插入和替换
  - 模板版本管理

#### 提示词优化
- **自动优化**：
  - 基于历史生成效果优化提示词
  - 提取有效模式
  - 生成效果分析

- **风格适配**：
  - 根据作品风格调整提示词
  - 多种写作风格支持
  - 自定义风格模板

## 4. 技术实现

### 4.1 前端实现

- **技术栈**：React + Ant Design + Axios
- **核心组件**：
  - Ant Design的Form、Modal、Progress组件
  - 实时进度显示组件
  - 流式输出组件

- **交互逻辑**：
  - 流式输出实时显示
  - 生成进度追踪
  - 错误处理和重试

### 4.2 后端实现

- **技术栈**：Python + Flask + SQLite + OpenAI API + Anthropic API
- **核心功能**：
  - 多AI提供商集成
  - 生成会话管理
  - 检查点存储和恢复
  - 概念融合算法

- **API设计**：
  - `POST /api/ai/generate`：通用生成接口
  - `POST /api/ai/generate_character`：生成角色
  - `POST /api/ai/generate_location`：生成地点
  - `POST /api/ai/generate_faction`：生成势力
  - `POST /api/ai/generate_item`：生成物品
  - `POST /api/ai/generate_relation`：生成关系
  - `POST /api/ai/concept_merge`：概念融合
  - `POST /api/ai/checkpoint/create`：创建检查点
  - `POST /api/ai/checkpoint/restore/<id>`：恢复检查点
  - `GET /api/ai/sessions`：获取会话列表
  - `POST /api/ai/sessions/<id>/pause`：暂停会话
  - `POST /api/ai/sessions/<id>/resume`：继续会话

## 5. 用户流程

### 5.1 配置AI提供商

1. 用户点击配置按钮
2. 用户选择AI提供商
3. 用户输入API密钥
4. 用户设置默认生成参数
5. 用户保存配置

### 5.2 生成角色

1. 用户选择生成类型为"角色"
2. 用户填写生成配置（数量、详细程度等）
3. 用户点击"开始生成"按钮
4. 系统显示生成进度
5. 用户预览生成的角色
6. 用户可选择融合、修改或保存

### 5.3 使用检查点

1. 用户开始批量生成
2. 系统自动创建检查点
3. 如果中断，用户选择"继续生成"
4. 系统从检查点恢复
5. 生成任务继续执行

### 5.4 概念融合

1. 用户生成新内容
2. 系统检测到与已有内容重复
3. 系统显示融合建议
4. 用户审核并确认融合
5. 系统执行融合操作
6. 生成最终内容

### 5.5 管理会话

1. 用户查看会话列表
2. 用户可以暂停正在进行的会话
3. 用户可以切换到其他会话
4. 用户可以导出或导入会话

## 6. 功能价值

- **高效生成**：通过AI批量生成，大幅提高创作效率
- **质量保障**：通过概念融合确保生成内容与设定一致
- **容错机制**：检查点机制确保生成过程可靠
- **灵活配置**：多提供商和多参数支持，适应不同需求
- **智能优化**：通过提示词管理和自动优化提高生成质量
