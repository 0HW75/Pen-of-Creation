# 世界构建系统模块功能定义

## 1. 模块概述

世界构建系统是AI小说创作工具"创世之笔"的核心功能之一，专门用于构建和管理复杂的小说世界观设定。该模块为用户提供从宏观到微观的世界构建工具，涵盖能量体系、文明发展、历史脉络、地理结构等各个方面，帮助用户创建独特、完整、自洽的小说世界。

## 2. 核心功能

### 2.1 能量与力量体系

#### 能量体系管理
- **能量类型**：
  - 魔法、斗气、灵气、异能、仙力等
  - 自定义能量类型
  - 能量来源、获取方式、储存方式

- **能量属性**：
  - 稀有度：常见/稀有/传说/禁忌
  - 稳定性：稳定/不稳定/极端
  - 与其他能量的相互作用

#### 力量等级构建
- **等级体系**：
  - 自定义等级数量和名称
  - 每等级的晋升要求
  - 等级特征和典型战斗力
  - 寿命延长设定
  - 社会地位关联

- **修炼方法**：
  - 不同的修炼路径
  - 修炼资源需求
  - 瓶颈突破方式

#### 能量形态
- **形态类型**：元素、时间、空间、物质、精神等
- **基本属性**：每种形态的特性和效果
- **相互作用规则**：不同形态之间的生克关系
- **视觉表现**：能量形态的外在表现特征

#### 力量代价
- **代价类型**：寿命、体力、精神、生命力等
- **触发条件**：何时需要支付代价
- **支付机制**：代价的计算方式
- **严重程度**：不同使用的风险等级
- **缓解方法**：降低代价的方式

### 2.2 文明与文化

#### 文明类型
- **发展水平**：原始/奴隶制/封建/工业/魔法/科幻等
- **文明特征**：
  - 政治体制、经济模式
  - 科技水平、魔法水平
  - 人口规模、领土范围
  - 文化特征、宗教信仰

#### 社会结构
- **阶级体系**：
  - 阶级层级和名称
  - 各阶级的典型职业
  - 特权和义务
  - 社会流动性

- **组织形式**：部落、城邦、王国、帝国、共和国等

#### 文化习俗
- **节日庆典**：节日名称、时间、意义、活动内容
- **仪式礼仪**：出生、成年、婚姻、丧葬等仪式
- **行为禁忌**：文化禁忌和社会规范
- **艺术形式**：音乐、绘画、舞蹈、文学等

### 2.3 历史脉络

#### 历史纪元
- **纪元划分**：命名、起止时间、时代特征
- **主要事件**：纪元内的重大事件
- **文明演变**：文明的发展和变化

#### 历史事件
- **事件类型**：战争、统一、分裂、革命、灾难等
- **事件详情**：
  - 时间、地点、主要参与者
  - 事件原因、过程、结果
  - 历史影响和意义

#### 历史人物
- **人物信息**：姓名、生卒年、身份、主要成就
- **历史贡献**：对文明/世界的影响
- **争议评价**：不同的历史评价

### 2.4 地理与区域

#### 地理区域
- **区域结构**：支持树状层级结构（世界-大陆-国家-省份-城市）
- **区域特征**：
  - 地形：平原、山脉、盆地、沙漠、海洋等
  - 气候：热带、温带、寒带、极端气候等
  - 资源：矿产、植物、动物、水源等

#### 维度与位面
- **位面类型**：主界、异界、镜像世界、精神空间等
- **位面规则**：每个位面的特殊法则
- **进入条件**：进入位面的方式和要求
- **空间属性**：位面的大小、稳定性和特征

#### 天体与星球
- **天体类型**：恒星、行星、卫星、彗星等
- **天体特征**：大小、轨道、周期等
- **世界位置**：世界在天体系统中的位置

### 2.5 自然法则

- **物理法则**：重力、温度、光照等基础物理规则
- **魔法法则**：魔法运作的基础规则
- **特殊法则**：这个世界特有的运行规则
- **法则变更**：特殊区域或情况下的规则变化

### 2.6 种族与生物

#### 种族设定
- **种族类型**：人类、精灵、兽人、龙族等
- **种族特征**：
  - 外貌特征：身高、体型、肤色、特殊标志
  - 生理特征：寿命周期、繁殖方式、代谢
  - 种族天赋：特有的能力和弱点
  - 社会形态：种族的社会组织形式
  - 分布区域：该种族的主要聚居地

#### 生物类型
- **普通生物**：普通动物、植物
- **异界生物**：来自其他维度的生物
- **特殊生物**：具有特殊能力的生物
- **传说生物**：神话中的生物

## 3. 界面设计

### 3.1 整体布局

- **顶部导航栏**：
  - 模块标题：世界构建
  - 世界选择器：切换不同世界
  - 操作按钮：保存、导出、AI生成

- **左侧导航**：
  - 能量体系、力量等级
  - 文明文化、社会结构
  - 历史脉络、地理区域
  - 维度位面、天体星球
  - 自然法则、种族生物

- **主内容区**：
  - 当前选中子模块的编辑界面
  - 列表视图或表单视图

- **右侧边栏**：
  - 世界概览统计
  - AI生成建议
  - 最近修改记录

### 3.2 核心组件

- **能量体系编辑器**：
  - 能量类型列表
  - 能量详情表单
  - 等级可视化图表

- **文明编辑器**：
  - 文明卡片网格
  - 文明详情表单
  - 文明关系图

- **历史时间线**：
  - 可视化时间轴
  - 事件详情面板
  - 纪元编辑器

- **地理区域树**：
  - 树状层级结构
  - 区域详情表单
  - 地图可视化占位

- **种族管理面板**：
  - 种族卡片
  - 种族详情编辑器

## 4. 技术实现

### 4.1 前端实现

- **技术栈**：React + Ant Design + ECharts
- **核心组件**：
  - Ant Design的Tree、Card、Form、Tabs组件
  - ECharts实现等级可视化、时间线
  - 树形组件实现地理层级结构

### 4.2 后端实现

- **技术栈**：Python + Flask + SQLite + OpenAI API
- **核心功能**：
  - 世界构建数据的CRUD操作
  - AI辅助生成世界构建内容
  - 世界设定的一致性检查

- **API设计**：
  - `GET /api/worlds/<id>/energy_systems`：获取能量体系
  - `POST /api/worlds/<id>/energy_systems`：创建能量体系
  - `GET /api/worlds/<id>/civilizations`：获取文明列表
  - `POST /api/worlds/<id>/civilizations`：创建文明
  - `GET /api/worlds/<id>/historical_eras`：获取历史纪元
  - `POST /api/worlds/<id>/historical_eras`：创建历史纪元
  - `GET /api/worlds/<id>/regions`：获取地理区域
  - `POST /api/worlds/<id>/regions`：创建地理区域
  - `GET /api/worlds/<id>/races`：获取种族列表
  - `GET /api/worlds/<id>/stats`：获取世界统计

## 5. 用户流程

### 5.1 创建世界

1. 用户在项目中创建新世界
2. 用户填写世界的基本信息
3. 系统创建空的世界框架

### 5.2 构建能量体系

1. 用户进入能量体系编辑界面
2. 用户创建能量类型
3. 用户设置力量等级和修炼方法
4. 用户定义能量形态和代价

### 5.3 创建文明

1. 用户进入文明编辑界面
2. 用户创建不同文明
3. 用户为每个文明设置政治、经济、文化等属性
4. 用户建立文明之间的关系

### 5.4 编写历史

1. 用户进入历史脉络编辑界面
2. 用户创建历史纪元
3. 用户添加重大历史事件
4. 用户关联历史人物到事件

### 5.5 构建地理

1. 用户进入地理区域编辑界面
2. 用户以树状结构创建区域层级
3. 用户为每个区域设置地理特征
4. 用户关联文明和种族到区域

## 6. 功能价值

- **系统性构建**：提供完整的世界构建框架，避免遗漏重要元素
- **内在一致性**：通过系统化的设定确保世界内部逻辑自洽
- **层次分明**：从宏观到微观，结构清晰地组织世界设定
- **关联管理**：维护世界各元素之间的复杂关系
- **AI辅助**：通过AI辅助生成世界构建内容，提高效率

## 7. 未来扩展

- **世界预览**：提供世界设定的可视化预览
- **规则模拟**：模拟世界运行规则，检验设定合理性
- **冲突检测**：自动检测世界设定中的矛盾和冲突
- **世界模板**：提供不同类型世界的预设模板

世界构建系统将成为用户创建独特小说世界的核心工具，通过系统化的设计和AI辅助，帮助用户构建完整、丰富、逻辑自洽的虚构世界。
