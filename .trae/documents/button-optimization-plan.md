# 按钮优化计划

## 当前问题

按钮太多太乱，需要重新组织按钮的层级关系和显示位置。

## 优化方案

### 1. 按钮分组

将按钮按功能分组，分为三组：

#### 第一组：主要操作按钮（顶部，蓝色系）

* 生成大纲

* 分解为卷纲（选中大纲后显示）

* 分解为章纲（选中卷纲后显示）

#### 第二组：配置按钮（顶部，彩色区分）

* 卷纲配置（蓝色）- 选中大纲后显示

* 章纲配置（紫色）- 选中卷纲后显示

* 版本管理（绿色）- 选中任何内容后显示

#### 第三组：工具按钮（第二行，灰色）

* 导入大纲

* 导出大纲

* 系统提示词

* 架构师管理

* 大纲结构

### 2. 按钮显示逻辑优化

#### 主操作按钮

```
[生成大纲] [分解为卷纲] [分解为章纲] [AI修改助手]
```

* 生成大纲：始终显示

* 分解为卷纲：选中大纲后显示

* 分解为章纲：选中卷纲后显示

* AI修改助手：选中大纲后显示

#### 配置按钮

```
[卷纲配置] [章纲配置] [版本管理]
```

* 卷纲配置：选中大纲后显示（蓝色）

* 章纲配置：选中卷纲后显示（紫色）

* 版本管理：选中大纲/卷纲/章纲后显示（绿色）

#### 工具按钮

```
[导入大纲] [导出大纲] [系统提示词] [架构师管理] [大纲结构]
```

* 始终显示

* 使用统一的灰色样式

### 3. 布局调整

#### 方案A：垂直分组

```
第一行（主操作）：生成大纲 | 分解为卷纲 | 分解为章纲 | AI修改助手
第二行（配置）：  卷纲配置 | 章纲配置 | 版本管理
第三行（工具）：  导入大纲 | 导出大纲 | 系统提示词 | 架构师管理 | 大纲结构
```

#### 方案B：水平分组（推荐）

```
[主要操作]                    [配置]                    [工具]
生成大纲 分解为卷纲          卷纲配置 章纲配置         导入大纲 导出大纲...
分解为章纲 AI修改助手        版本管理                  系统提示词...
```

### 4. 按钮样式统一

#### 主操作按钮

* 生成大纲：primary（蓝色）

* 分解为卷纲：primary（蓝色）

* 分解为章纲：primary（蓝色）

* AI修改助手：default（灰色）

#### 配置按钮

* 卷纲配置：primary（蓝色 #1890ff）

* 章纲配置：primary（紫色 #722ed1）

* 版本管理：primary（绿色 #52c41a）

#### 工具按钮

* 全部使用 default（灰色）

* 减少视觉混乱

* 用户能快速找到需要的功能

* 配置按钮使用不同颜色便于
