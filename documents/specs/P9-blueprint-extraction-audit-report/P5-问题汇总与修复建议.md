## 二、🔴 高严重问题（必须修复）

### 问题1：前端只有9种类型，后端支持13种

#### 问题描述
- 前端 `Step1WithStream.jsx` 只发送9种元素类型
- 后端 `worldview_element_extractor.py` 支持13种类型
- 用户无法提取文明、社会阶层、政治体系、经济体系、文化习俗这5种设定

#### 严重程度
**高严重** - 功能缺失

#### 代码位置
- 前端：`Step1WithStream.jsx` L394
- 后端：`worldview_element_extractor.py` L65-71

#### 差异详情

| 类型 | 前端 | 后端 |
|------|------|------|
| `civilizations` | ❌ | ✅ |
| `social_classes` | ❌ | ✅ |
| `political_systems` | ❌ | ✅ |
| `economic_systems` | ❌ | ✅ |
| `cultural_customs` | ❌ | ✅ |

#### 修复方案

**文件**：`frontend/src/components/CreateWorldWizard/Step1WithStream.jsx` L394

**修改前**：
```javascript
target_types: [
  'characters', 'locations', 'factions', 'items',
  'world_architecture', 'energy_systems', 'society_systems',  // ❌ 旧名称
  'timeline_events', 'relations'
]
```

**修改后**：
```javascript
target_types: [
  'characters', 'locations', 'factions', 'items',
  'world_architecture', 'energy_systems',
  'civilizations',        // ✅ 新增
  'social_classes',       // ✅ 新增
  'political_systems',     // ✅ 新增
  'economic_systems',     // ✅ 新增
  'cultural_customs',     // ✅ 新增
  'timeline_events', 'relations'
]
```

#### 修复验证
```bash
# 验证前端发送的类型数量
grep -n "target_types" Step1WithStream.jsx | head -5
# 应该是13种，不是9种
```

### 问题2：timeline_events 映射到 historical_event

#### 问题描述
- 提取的"时间线事件"被映射到 `HistoricalEvent` 表
- 但 `HistoricalEvent` 是存储具体历史事件的
- `Timeline` 表才是存储完整时间线的（个人/组织/世界生命周期）

#### 严重程度
**高严重** - 数据结构错误

#### 代码位置
- `worldview_generation.py` L139

#### 修复方案

**修改前**：
```python
'timeline_events': 'historical_event'  # ❌ 错误
```

**修改后**：
```python
'timeline_events': 'timeline'  # ✅ 正确
```

#### 修复验证
```bash
# 验证映射是否正确
grep -n "timeline_events" worldview_generation.py
# 应该是 'timeline' 而不是 'historical_event'
```

### 问题4：EnergySystemGenerator 传入不存在的 project_id

#### 问题描述
- `EnergySystemGenerator.save_to_database()` 传入 `project_id` 字段
- 但 `EnergySystem` Model **没有** `project_id` 字段
- 会导致数据库错误（IntegrityError 或 AttributeError）

#### 严重程度
**高严重** - **会导致数据库错误**

#### 代码位置
- `energy_system_generator.py` L40-56

#### 修复方案

**修改前**：
```python
energy_system_data = {
    'world_id': world_id,
    'project_id': project_id,  # ❌ Model没有此字段
    'name': data.get('name', ''),
    # ...
}
```

**修改后**：
```python
energy_system_data = {
    'world_id': world_id,
    # 'project_id': project_id,  # 删除
    'name': data.get('name', ''),
    # ...
}
```

#### 修复验证
```bash
# 验证 Model 是否有 project_id
grep -n "project_id" models.py | grep -i energy
# 应该没有输出
```
