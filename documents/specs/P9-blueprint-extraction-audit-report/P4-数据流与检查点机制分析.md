### 2.2 index.jsx 接收并保存数据

**文件**：`CreateWorldWizard/index.jsx` L52-68

```javascript
const handleStep1Complete = (data) => {
  setStep1Data(data);  // ✅ 保存完整数据

  setStep2Data({
    extractionId: `ext_${data.projectId}_${Date.now()}`,
    elements: data.extractionResult.elements,
    selectedElements: {},  // 初始为空

    // ⚠️ contentScope 丢失！
  });

```

### 2.3 问题：storyContext 和 contentScope 丢失

| 数据项 | 来源 | 目标 | 状态 |
|-------|------|------|------|
| `storyContext` | Step1 onComplete | step2Data | ❌ **未保存** |
| `contentScope` | Step1 onComplete | step2Data | ❌ **未保存** |
| `checkpointId` | Step1 onComplete | step2Data | ❌ **未保存** |
| `elements` | Step1 onComplete | step2Data | ✅ 已保存 |

**影响**：
- Step2 组件无法访问 `storyContext`
- Step2 组件无法访问 `contentScope`
- 如果用户从 Step2 返回 Step1 重新选择，之前的检查点ID丢失

### 3.3 index.jsx 处理 Step2 完成

**文件**：`CreateWorldWizard/index.jsx` L112-153

```javascript
const handleStep2Complete = async (selectedElements) => {
  // 1. 更新 step2Data
  setStep2Data(prev => ({ ...prev, selectedElements }));

  // 2. 调用创建批次 API
  const response = await worldviewGenerationApi.createGenerationBatches({
    extraction_id: step2Data.extractionId,
    elements: step2Data.elements,           // ✅ 全量元素
    selected_elements: selectedElements,     // ✅ 用户选择
    parent_checkpoint_id: step1Data.checkpointId,  // ✅ 从 step1Data 获取
    batch_config: {
      batch_size: 5,
      priority_order: [...],
      generation_strategy: "moderate"
    }
  });

  // 3. 保存 step3Data
  setStep3Data({
    generationSessionId: response.data.data.generation_session_id,
    batches: response.data.data.batches,
    generatedWorldId: null,
    parentCheckpointId: step1Data.checkpointId,  // ✅ 正确传递
    // ⚠️ storyContext 未保存！
  });
};
```

### 3.4 问题：storyContext 仍然丢失

| 数据项 | 来源 | 目标 | 状态 |
|-------|------|------|------|
| `storyContext` | step1Data | step3Data | ❌ **未传递** |
| `parentCheckpointId` | step1Data | step3Data | ✅ 已传递 |

**影响**：
- Step3 生成时无法获取完整的故事上下文
- `storyContext` 包含 `outline`（大纲）、`volume`（卷）、`chapters`（章节）信息
- 这些信息对于生成更准确的世界观设定很重要

## 七、数据流问题汇总

### 7.1 问题列表

| # | 问题 | 严重程度 | 位置 | 影响 |
|---|------|---------|------|------|
| 1 | `storyContext` 在 Step1→Step2 时丢失 | 中 | index.jsx L64-68 | Step2 无法使用故事上下文 |
| 2 | `storyContext` 在 Step2→Step3 时丢失 | 中 | index.jsx L150 | Step3 生成时缺少上下文 |
| 3 | `contentScope` 在 Step1→Step2 时丢失 | 低 | index.jsx L64-68 | 可能影响重新提取 |
| 4 | `checkpointId` 未显式传递到 step2Data | 低 | index.jsx L64-68 | 已通过 step1Data 间接访问 |

**修改后**：
```javascript
setStep2Data({
  extractionId: `ext_${data.projectId}_${Date.now()}`,
```
