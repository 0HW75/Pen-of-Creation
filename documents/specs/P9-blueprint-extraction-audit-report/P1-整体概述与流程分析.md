## 一、项目背景

### 1.1 功能概述

故事蓝图提取设定功能是 AI 小说编辑器 的核心功能之一，允许用户从已有的故事内容（大纲、章节）中提取潜在的世界观设定元素，并根据这些元素自动生成详细的设定内容。

### 1.2 涉及技术栈

| 层级 | 技术栈 |
|-----|-------|
| 前端 | React, Ant Design, TypeScript |
| 后端 | Python FastAPI |
| 数据库 | PostgreSQL |
| AI服务 | OpenAI GPT-4 |

### 1.3 涉及代码文件

**前端组件**：
- `CreateWorldWizard/index.jsx` - 向导容器，管理步骤状态
- `CreateWorldWizard/Step1WithStream.jsx` - 蓝图内容选择与元素提取
- `CreateWorldWizard/Step2ConfirmList.jsx` - 提取元素确认与选择
- `CreateWorldWizard/Step3Generate.jsx` - 详细设定生成

**后端API**：
- `worldview_extraction.py` - 蓝图元素提取API
- `worldview_generation.py` - 批次生成API
- `worldview_storage.py` - 存储API

**后端服务**：
- `worldview_element_extractor.py` - 元素提取服务
- `checkpoint_service.py` - 检查点服务
- `generation/generators/*.py` - 各类型生成器

### 2.2 各步骤详细说明

#### Step 1 - 选择蓝图内容

**前端组件**：`Step1WithStream.jsx`

**用户操作**：
1. 选择项目（project）
2. 选择内容范围（content_scope）：
   - 全部大纲（full）
   - 单卷（volume）
   - 单章（chapter）

**发送请求**：
```javascript
{
  project_id: number,
  content_scope: {
    type: "full" | "outline" | "volume" | "chapter",
    outline_id?: number,
    volume_id?: number,
    chapter_id?: number
  },
  extraction_config: {
    target_types: string[],  // ⚠️ 问题1：前端只有9种
    strategy: "infer_potential",
    include_evidence: true
  }
}
```

**后端处理**：
1. 获取指定范围的内容
2. 调用 AI 提取元素
3. 合并多章节结果（如选择多章）
4. 保存检查点
5. 流式返回结果

**返回数据**：
```javascript
{
  type: "complete",
  elements: { /* 各类元素数组 */ },
  statistics: { /* 各类元素数量 */ },
  story_context: { outline, volume, chapters },
  checkpoint_id: number
}
```

#### Step 2 - 确认提取清单

**前端组件**：`Step2ConfirmList.jsx`

**用户操作**：
1. 查看提取的元素列表
2. 选择要生成详细设定的元素
3. 可选：AI 整合相似元素
4. 点击下一步

**传递数据**：
```javascript
{
  extractionId: string,
  elements: { /* 全量元素 */ },
  selectedElements: { /* 用户选择的元素ID */ }
}
```

#### Step 3 - 生成详细设定

**前端组件**：`Step3Generate.jsx`

**用户操作**：
1. 查看生成的批次列表
2. 启动生成
3. 流式查看生成进度
4. 生成完成后创建世界

**调用API**：
```javascript
// 创建批次
{
  extraction_id: string,
  elements: { /* 全量元素 */ },
  selected_elements: { /* 用户选择的元素ID */ },
  parent_checkpoint_id: number,
  batch_config: { batch_size, priority_order, generation_strategy }
}

// 执行批次生成
{
  batch_id: string,
  entity_type: string,
  elements: [],
  world_id: number,
  project_id: number,
  story_context: { outline, volume, chapters },
  parent_checkpoint_id: number
}
```

## 五、本篇小结

本篇介绍了故事蓝图提取设定功能的整体架构和流程。功能分为三个步骤：选择蓝图内容、确认提取清单、生成详细设定。后端涉及提取API、生成API、存储API以及多个Generator模块。数据库包含13个设定相关表。

**已发现的潜在问题**（将在后续篇章详细分析）：
1. 前端 `target_types` 只有9种，后端支持13种
2. `timeline_events` 映射到 `historical_event` 可能不正确
3. `world_architecture` 映射到不存在的Generator
