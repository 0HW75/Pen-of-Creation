# P8 - 从故事蓝图智能构建世界观规格说明书

## 一、功能概述

### 1.1 功能目标

在世界观管理功能中，添加根据选定的项目的故事蓝图（大纲/卷纲/章纲）内容，让AI智能新建/完善/更新世界观和其中的各项条目（角色、地点、势力、物品等）的功能。

**核心入口**：
1. **创建世界时** - 点击"+ 创建世界"时可选择AI从蓝图生成
2. **世界观管理页** - 已有世界的AI智能构建入口

### 1.2 核心价值

1. **智能化设定生成**：从已有故事内容中自动提取和生成世界观设定
2. **保持一致性**：确保世界观设定与故事蓝图内容相互匹配
3. **提升效率**：减少手动创建设定的工作量
4. **发现遗漏**：通过AI分析发现故事中未明确设定的元素

### 1.3 使用场景

| 场景 | 描述 | 入口位置 |
|------|------|----------|
| 新建世界观 | 根据故事大纲快速生成基础世界观框架 | 创建世界模态框 |
| 完善设定 | 根据卷纲/章纲内容补充缺失的角色、地点等设定 | 世界观管理页 |
| 更新同步 | 故事修改后同步更新相关世界观设定 | 世界观管理页 |
| 一致性检查 | 检查故事与设定之间的不一致之处 | 世界观管理页 |
